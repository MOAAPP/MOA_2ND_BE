# AI 금융 학습 및 Discord 자동화 백엔드 통합

2026-11-15: 공식 main b9478a0(금융 엔진·ML PR #16 포함)을 기준으로 통합했다.

## 범위
- 기존 FastAPI 개인화 퀴즈·브리핑을 재사용한다. 관심사, 미해결 오답 우선 복습, 힌트, 사용자·날짜별 답안, 주제별 학습 통계와 연속 학습일을 제공한다.
- 답안의 정답 판정은 저장된 정답으로 수행하고 AI는 해당 선택의 이유만 설명한다. 실제 제공자 성공/실패, 모델, 규칙 기반 대체를 구분한다.
- SQLite 또는 비공개 Blob에 학습 및 카드 상태를 보관한다. 카드 렌더링은 기존 프론트 저장소의 Node 서버를 사용하며 여기에서 재구현하지 않는다.
- 카드 생성·조회·재시도·구독 등의 FastAPI 연결 API를 Swagger에 노출한다.
- 사용자 S01–S20과 금융 관측일 2026-11-04를 유지한다. 학습/발송 날짜는 별도다.

## 공통 코드와 개인 실행 설정
개인 키, Discord 주소, test 배포 도메인은 코드에 포함하지 않는다. 팀 운영 환경의 기존 값을 덮어쓰지 않는다.
- BE: 기존 MOA_AI_API_KEY / MOA_AI_BASE_URL / MOA_AI_MODEL을 그대로 사용한다. FactChat도 기존 OpenAI 호환 설정으로 연결 가능하다.
- BE: MOA_RENDER_API_BASE는 해당 환경의 호환 Node 카드 서버 주소. MOA_INTERNAL_SECRET은 FE 서버와 일치해야 한다. 호환 FE 변경 반영 전 카드 어댑터는 동작을 보장하지 않는다.
- FE Node: 기존 Discord Webhook과 PIXABAY_API_KEY 또는 PEXELS_API_KEY 사용. 키는 브라우저 번들에 넣지 않는다.
- EC2: MOA_RUNTIME_DIR을 지속 가능한 쓰기 경로로 설정하고 기존 gateway 정책을 유지한다. Vercel에서 영구 저장이 필요하면 비공개 Blob 설정을 사용한다.
- 정기 실행은 배포 환경의 스케줄러가 필요하다. BE 코드 머지만으로 EC2의 매일 오전 8시 실행이 추가되지는 않는다. test FE에서는 UTC 23:00 Cron을 사용한다.

## 검증
- 공식 최신 main과 합친 로컬 사본의 170개 테스트 통과.
- test 배포에서 FactChat claude-haiku-4-5-20251001로 새 퀴즈, 카드 문장, 정답/오답 해설 실호출 성공(source=llm, status=live).
- 사진 제공자 연결 후 모의 ETF 테스트 카드 4장 생성, 서로 다른 Pixabay 사진 4개와 출처 저장, Discord 전송 성공(status=sent, sends.ok=true).
- 예약 경로 수동 실행 후 데일리 카드 4장 수신은 사용자가 확인했다. 오전 8시 자동 수신은 아직 별도 확인이 필요하다.

## 남은 제한
- 기존 홈의 Node 모닝 브리핑 호출은 BE 개인 키 설정만으로 자동 연결되지 않는다. 이 PR을 전체 프론트 AI 브리핑 완료로 보고하지 않는다.
- 합성 사용자 시연이며 실제 로그인 사용자 인증/권한 서비스가 아니다.
- 뉴스 출처 검사는 HTTPS·날짜·중복 메타데이터 검사이며 기사 내용의 사실성을 인증하지 않는다.
